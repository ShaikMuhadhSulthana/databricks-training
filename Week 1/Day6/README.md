# College Management System (CMS) – SQL Practice Project

## Overview

The College Management System (CMS) SQL Practice Project is designed to provide hands-on experience with SQL using a realistic academic database environment. The project models the core operations of a college by managing departments, staff members, students, subjects, and examination records through relational database design.

This practice database is intended for learning and improving SQL skills through structured query exercises ranging from basic data retrieval to advanced analytical reporting.

---

## Project Structure

The database consists of five main tables:

* `Department`
* `Staff`
* `Student`
* `Subject`
* `Mark`

These tables are connected using primary and foreign key relationships to simulate real-world database interactions within a college management system.

---

## SQL Concepts Covered

This project includes 50 practice queries covering important SQL concepts such as:

* Joins and Relationships
* Aggregate Functions
* Filtering and Sorting
* Subqueries
* Grouping and HAVING Clause
* NULL Handling
* Window Functions
* Ranking Functions
* Analytical Queries

Advanced SQL functions including `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`, `NTILE()`, and `CUME_DIST()` are also implemented as part of the practice set.

---

## Practice Objectives

The queries in this project are designed to help in:

* Understanding relational database design
* Writing optimized SQL queries
* Performing analytical calculations
* Generating reports from structured data
* Working with real-world query scenarios
* Strengthening problem-solving skills in SQL

The practice set progresses from beginner-level queries to advanced analytical and reporting queries.
